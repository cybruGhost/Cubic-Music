# Contributing to Cubic Music

Thank you for your interest in contributing to **Cubic Music**! ❤️ Every contribution, whether it's code, testing, documentation, translations, or ideas, helps make the project better.

> [!IMPORTANT]
> **Please open a GitHub Issue before starting work on a feature or major fix.**
>
> My local development branch is often **ahead of the public repository**, so GitHub may not always reflect what I'm actively building. Starting a discussion first helps avoid duplicate work, conflicts, or implementing features that are already in progress.

## Project Philosophy

Cubic Music prioritizes **stability, usability, and long-term quality** over rushing out features.

A flashy UI or a long feature list means very little if the experience isn't reliable. New designs, animations, and features are only added when they make sense, solve a real problem, and are stable enough to maintain.

When contributing, please keep these principles in mind:

* Build features that have a clear purpose.
* Prioritize reliability over complexity.
* Keep the user experience simple, intuitive, and consistent.
* Avoid unnecessary UI changes or visual effects that don't improve usability.
* Focus on quality rather than quantity.

## Ways to Contribute

* 🐞 Report bugs
* 💡 Suggest new features
* 🔧 Fix bugs
* ✨ Improve the user experience
* 🌍 Help translate the app
* 📖 Improve documentation
* 🧪 Test new releases

## Reporting Bugs

Please include:

* Cubic Music version
* Android version
* Device model
* Steps to reproduce
* Expected result
* Actual result
* Screenshots or relevant logs (if available)

Please **do not** include passwords, tokens, API keys, cookies, or any personal information.

## Pull Requests

Before opening a pull request:

* Discuss major changes in a GitHub Issue first.
* Keep changes focused on a single purpose.
* Test your changes thoroughly.
* Follow the existing coding style.
* Write clear commit messages.

## Development

1. Fork the repository.
2. Create a feature branch.
3. Make and test your changes.
4. Commit and push your branch.
5. Open a Pull Request.

Thank you for helping improve **Cubic Music**. Every thoughtful contribution helps make the app better for everyone.
